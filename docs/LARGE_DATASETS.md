# Large inputs and memory admission

`memory_budget_mb="auto"` is an admission estimate for selected working allocations. An explicit positive MiB integer sets an admission budget. Neither is a total-process RSS bound, a reservation or an OOM guarantee. Array-like conversion can allocate before shape inspection, and internal versus explicit validation have different accounting. Profile input conversion, model, batch and process costs on your workload; do not infer RAM from serialized bytes. Prepared sessions retain encoded input and a model copy, and should be amortized across repeated requests. See [technical costs](../benchmarks/TECHNICAL.md) and [API](API.md).
