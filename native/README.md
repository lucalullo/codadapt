# Historical native inference sources

The C++ files are preserved byte-for-byte from the supplied public 2.1.0 repository. The 2.2.0 distribution deliberately does not build or ship the optional C++ backend. These files are reference-only. If native inference is required, retain a compatible, previously qualified 2.1.0 wheel or follow the native-build procedure of the historical 2.1.0 source. No native build of the current checkout or return of the backend is promised. Native-platform performance and prior qualification receipts cannot be inherited by a new binary. The current backend builds a pure-Python wheel only. Historical workflow filenames now validate that Python distribution and do not certify a native binary. See [compatibility](../docs/COMPATIBILITY.md).
